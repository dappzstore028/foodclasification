      Panduan & Script Google Drive (Code.gs)

      Mendukung paginasi ratusan foto (sz=w256) & sinkronisasi model cloud

      Langkah 1

      Siapkan Folder Drive

      Buat 2 folder di Google Drive untuk foto Real Food dan Junk Food, lalu salin link masing-masing folder.

      Langkah 2

      Pasang Code.gs

      Buka script.google.com → Proyek Baru → tempel kode di bawah ini ke Code.gs dan simpan.

      Langkah 3

      Deploy Web App

      Klik Terapkan → Deployment Baru → Aplikasi Web, atur akses ke Siapa saja (Anyone), lalu salin URL Web App.
